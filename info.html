SOBRE EL PROYECTO

Una plataforma creada para la comunidad universitaria

BUSUCR es un proyecto académico desarrollado con el propósito de facilitar el acceso a información relacionada con la comunidad universitaria.

Para su desarrollo se combinan conocimientos de programación, diseño web, organización de información y experiencia de usuario.

01

Tecnología

Aplicamos conocimientos de desarrollo para crear una plataforma funcional.

02

Diseño

Buscamos una experiencia sencilla, clara y agradable para el usuario.

03

Colaboración

El proyecto representa nuestro trabajo y aprendizaje como equipo.
